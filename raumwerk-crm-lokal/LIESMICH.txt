raumwerk CRM – lokale Version
=============================

Was Sie brauchen
  Python 3 (kostenlos). Windows: im Microsoft Store nach „Python 3“ suchen.
  Mac: https://www.python.org/downloads/
  Unter Windows bei der Installation „Add python.exe to PATH“ anhaken.
  Sonst nichts – keine Zusatzpakete, kein Konto, keine Kosten.

Starten
  Mac:      Doppelklick auf „raumwerk CRM starten.command“
            (beim ersten Mal: Rechtsklick → Öffnen → Öffnen)
  Windows:  Doppelklick auf „raumwerk CRM starten.bat“
  Oder im Terminal in diesem Ordner:  python3 raumwerk_crm.py

  Der Browser öffnet sich automatisch mit dem CRM.
  Das schwarze Fenster offen lassen, solange Sie arbeiten.
  Beenden: Fenster schließen oder Strg + C.

Auf dem Handy öffnen
  Am Computer statt der normalen Startdatei doppelklicken:
    Windows:  „raumwerk CRM starten (Handy).bat“
    Mac:      „raumwerk CRM starten (Handy).command“
  Fragt Windows nach dem Netzwerkzugriff: „Private Netzwerke“ erlauben.
  Im CRM am Computer unter Einstellungen → 04 / Handy den QR-Code mit dem
  Handy scannen. Das Handy muss im gleichen WLAN sein, der Computer muss laufen.
  Alle Änderungen vom Handy landen direkt in leads.json auf dem Computer.

  Der Link im QR-Code enthält einen persönlichen Zugangsschlüssel – nicht
  weitergeben. Neuer Schlüssel: raumwerk-daten/handy-zugang.txt löschen und
  neu starten (danach den QR-Code erneut scannen).

Wo die Leads liegen
  Im Ordner „raumwerk-daten“ neben dem Skript:
    leads.json      die aktuellen Daten
    sicherungen/    eine automatische Sicherung pro Tag (die letzten 60 Tage)

  Den ganzen Ordner können Sie z. B. in iCloud Drive, OneDrive oder
  Dropbox legen – dann sind die Leads zusätzlich gesichert.
  Wichtig: nur auf einem Computer gleichzeitig öffnen.

Leads aus der Online-Version übernehmen
  Online-Version → Einstellungen → „Sicherung herunterladen“.
  Lokale Version → Einstellungen → „Sicherung einspielen“.

Datenschutz
  Mit der normalen Startdatei ist das CRM nur auf diesem Computer erreichbar.
  Mit der Handy-Startdatei zusätzlich im eigenen WLAN – aber nur mit dem
  Zugangsschlüssel. Aus dem Internet ist es nie erreichbar.
  Nur die Schriften werden von Google Fonts geladen.
